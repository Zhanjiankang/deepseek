# 物含妙理 - 物理教学网站

## 项目概述

这是一个专为物理教学设计的网站，包含多个功能模块，支持教学资源管理、班级纪实、可视化教学等功能。

**目录命名原则：**

## 模块说明书

### 1. 主页面模块 (index.html)

**功能说明：**
- 显示最近更新、随机点名、今日格言、每日一问
- 提供导航到各个功能模块
- 响应式设计，支持多设备访问

**数据文件：**
- `latest-data.js` - 最近更新数据
- `questions.js` - 问题数据
- `quotes.js` - 格言数据
- `students.js` - 学生名单数据

**维护方法：**
- 修改`latest-data.js`更新最新内容
- 修改`questions.js`添加新问题
- 修改`quotes.js`更新格言
- 修改`students.js`更新学生名单

### 2. 班级纪实模块 (班级纪实/)

**功能说明：**
- 展示班级活动图片轮播
- 显示班级纪实列表
- 支持图片点击切换和自动播放

**数据文件：**
- `class-records.js` - 班级纪实数据
- `carousel-images.js` - 轮播图片配置

**维护方法：**
- 在`class-records.js`中添加新的班级记录
- 在`carousel-images.js`中添加新的轮播图片
- 将图片文件放入`photos/`目录

### 3. 教学模块 (教学/)

#### 3.1 可视化教学 (教学/可视化/)
**功能说明：**
- 动态展示课程内容
- 支持课程网格布局
- 异步加载课程数据

**维护方法：**
- 修改`config.js`配置课程列表
- 在`must1/`等子目录中添加课程内容
- 每个课程目录需要包含`list.js`文件

#### 3.2 重难点教学 (教学/重难点/)
**功能说明：**
- 展示物理重难点内容
- 与可视化模块相同的架构
- 专注于难点知识讲解

**维护方法：**
- 与可视化模块维护方法相同
- 专注于重难点内容的更新

### 4. 理论模块 (理论/)

**功能说明：**
- 高中物理理论知识
- 竞赛一轮相关内容
- 理论知识点整理

**维护方法：**
- 直接修改对应HTML文件内容
- 保持理论知识的时效性

### 5. 工具模块 (工具/)

**功能说明：**
- 班级排名分析
- 物理相关图片展示
- 参考资料分享

**维护方法：**
- 更新排名数据
- 添加新的图片资源
- 更新参考文章内容

## 维护更新指南

### 样式维护

**全局样式文件：** `style.css`
- 所有页面的样式都集中在此文件中
- 修改样式时注意保持一致性
- 使用CSS变量便于主题定制

```css

    --light-blue: #e3f2fd;         /* 浅蓝色背景 */
}
```

## 常见问题解决

### 页面显示问题
1. **样式不生效**：检查CSS文件路径是否正确
2. **功能不工作**：检查JavaScript控制台错误
3. **图片不显示**：检查图片路径和文件是否存在

### 数据加载问题
1. **数据不显示**：检查数据文件格式是否正确
2. **加载动画不停**：检查数据文件是否存在且格式正确
3. **链接失效**：检查文件路径或URL是否正确

### 性能优化建议
1. 压缩图片资源
2. 合并CSS和JavaScript文件
3. 使用CDN加速静态资源
4. 定期清理无用文件
